# TRANSFER TO UK — website

Static, responsive website in Ukrainian. No build step or framework required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy to Vercel

Import this folder/repository as a static project. Framework preset: **Other**. Build command: empty. Output directory: `.`.

## WhatsApp enquiries

The enquiry form builds a message and opens WhatsApp to **+380 988 536 842**. The visitor confirms and sends the message in WhatsApp. No form data is stored by this static website.

## Files

- `london-mobile.mp4` — optimized, muted-colour portrait video supplied for the mobile hero.
- `london-poster.webp` — compressed poster image from the supplied video, used on desktop and as the video poster.
- `favicon.svg` — custom minimal route mark.

## Before production

Please confirm the destination cities, actual departure schedule, passenger/baggage conditions, parcel terms, and that the Ukrainian number is the intended WhatsApp recipient.
